# 项目路线图

本文档概述了Cursor远程控制项目的未来计划和功能路线图。

## 当前状态

Cursor远程控制项目目前处于初始版本，已实现以下核心功能：

- 基于Redis的实时通信
- AppleScript控制Cursor应用
- 基础聊天功能（Ask、Chat、Agent模式）
- 基本的Cursor操作支持

## 优先级分配

功能优先级由以下因素决定：

1. 安全和稳定性 - 最高优先级
2. 核心功能改进 - 高优先级
3. 用户反馈和需求 - 中高优先级
4. 平台扩展 - 中等优先级
5. 实验性功能 - 低优先级
