# CursorRemote 持续运行自动重启机制

## 概述

为了解决服务达到最大重启次数后完全停止的问题，我们实现了一套持续运行策略，确保服务能够长期稳定运行。

## 核心改进

### 1. 双重重启机制

- **常规重启**: 正常情况下的重启机制（最多5次）
- **紧急重启**: 延长模式下的备用重启机制（最多3次）

### 2. 延长检查模式

当常规重启达到上限时，系统不会停止，而是：
- 进入延长检查模式
- 检查间隔从2分钟延长到10分钟
- 启用紧急重启机制

### 3. 自动重置机制

- **成功重置**: 服务正常运行1小时后重置常规重启计数
- **强制重置**: 6小时后无条件重置所有计数器
- **紧急重置**: 12小时后重置紧急重启计数

### 4. 手动控制

- 支持 `USR1` 信号手动重置重启计数器
- 支持 `ENABLE_AUTO_RESTART` 环境变量控制自动重启

## 配置参数

```javascript
const config = {
  // 基础配置
  checkInterval: 120000,           // 正常检查间隔: 2分钟
  failureThreshold: 5,             // 连续失败阈值: 5次
  restartCooldown: 120000,         // 重启冷却期: 2分钟
  maxRestarts: 5,                  // 最大常规重启次数: 5次
  
  // 持续运行配置
  extendedCheckInterval: 600000,   // 延长检查间隔: 10分钟
  emergencyRestartThreshold: 10,   // 紧急重启阈值: 连续失败10次
  maxEmergencyRestarts: 3,         // 最大紧急重启次数: 3次
  
  // 重置配置
  resetInterval: 3600000,          // 成功重置间隔: 1小时
  forceResetInterval: 21600000,    // 强制重置间隔: 6小时
  emergencyResetInterval: 43200000 // 紧急重置间隔: 12小时
};
```

## 运行状态

### 正常模式
- 检查间隔: 2分钟
- 可用重启: 常规重启（5次）
- 状态显示: "正常检查模式"

### 延长模式
- 检查间隔: 10分钟
- 可用重启: 紧急重启（3次）
- 状态显示: "延长检查模式"

## 使用方法

### 启动监控器
```bash
npm run auto-restart
# 或
node auto-restart.js
```

### 手动重置重启计数器
```bash
# 发送USR1信号到监控器进程
kill -USR1 <监控器进程ID>
```

### 禁用自动重启
```bash
export ENABLE_AUTO_RESTART=false
npm run auto-restart
```

## 状态监控

监控器会显示以下信息：
- 运行时间
- 服务状态
- 常规重启次数 (x/5)
- 紧急重启次数 (x/3)
- 连续失败次数
- 总失败次数
- 严重错误计数
- 当前模式（正常/延长）
- 下次强制重置时间

## 重启触发条件

### 常规重启触发
1. 连续失败5次
2. 检测到严重错误
3. 发现卡住的命令（30分钟未处理）

### 紧急重启触发
1. 处于延长模式
2. 自上次成功以来连续失败10次
3. 紧急重启次数未达上限（3次）

## 故障恢复流程

```
服务启动 → 正常监控 → 检测到问题 → 常规重启（最多5次）
    ↓
达到常规重启上限 → 进入延长模式 → 紧急重启（最多3次）
    ↓
达到紧急重启上限 → 等待自动重置 → 6小时后强制重置
    ↓
重置成功 → 回到正常监控
```

## 优势

1. **永不停止**: 即使达到重启上限也不会完全停止监控
2. **渐进策略**: 通过延长检查间隔减少系统负载
3. **多重保障**: 常规重启 + 紧急重启 + 自动重置
4. **手动控制**: 支持手动重置和禁用功能
5. **智能恢复**: 服务恢复后自动退出延长模式

## 注意事项

- 延长模式下检查间隔较长，可能延迟发现问题
- 紧急重启应谨慎使用，仅在严重故障时触发
- 建议定期检查监控器日志，了解服务健康状况
- 如需立即重置，可使用 `kill -USR1` 信号

这套机制确保了 CursorRemote 服务能够持续稳定运行，即使在遇到持续性问题时也不会完全停止服务。
