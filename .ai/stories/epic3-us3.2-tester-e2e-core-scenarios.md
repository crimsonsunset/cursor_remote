## Tasks

{
1. - [ ] 根据PRD第2.2节"用户场景"和第4.3节"功能需求"梳理出所有核心用户场景列表。
2. - [ ] 为每个核心用户场景设计详细的端到端测试用例，包括：
   1. - [ ] 前置条件。
   2. - [ ] 操作步骤。
   3. - [ ] 预期结果 (包括数据在`commands`和`results`表中的状态，客户端的显示)。
   4. - [ ] 基本的响应时间感受（是否"不太慢"）。
3. - [ ] 执行所有设计的测试用例。
4. - [ ] 记录每个测试用例的执行结果，包括任何偏差或问题。
5. - [ ] 对于失败的测试用例，提供详细的复现步骤和相关日志/截图。
6. - [ ] 汇总测试结果，评估核心功能的整体正确性和稳定性。
}
